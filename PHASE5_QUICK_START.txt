5️⃣  LOAD TEST OVERVIEW

   Test          Duration   Load Pattern        Purpose
   ─────────────────────────────────────────────────────────────────
   Smoke         30 sec     1 VU                Sanity check
   Load          5 min      10→25→50 VU         Normal operation
   Spike         5 min      10→100→10 VU        Recovery testing
   Stress        30 min     100→500→1000 VU     Breaking point
   Endurance     60 min     25 VU constant      Stability & leaks

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

6️⃣  EXPECTED RESULTS (PASS CRITERIA)

   ✅ Smoke Test
      - All 5 endpoints respond (200 OK)
      - P95 latency < 500ms

   ✅ Load Test
      - Error rate < 5%
      - P99 latency < 2000ms
      - Throughput > 10 req/s

   ✅ Spike Test
      - Error rate < 10% during spike
      - Recovery < 2 minutes
      - No cascading failures

   ✅ Stress Test
      - Breaking point identified > 1000 VU
      - Graceful degradation
      - Error rate < 15% at extreme load

   ✅ Endurance Test
      - Latency stable throughout
      - Error rate < 2%
      - No memory leak indicators

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

7️⃣  TROUBLESHOOTING

   ❌ k6 not found
   > where k6
   If empty, install from: https://github.com/grafana/k6/releases

   ❌ Connection refused (localhost:8000)
   > kubectl get pods -n ryzanstein-staging  # Check pods running
   > kubectl port-forward -n ryzanstein-staging svc/ryzanstein-api 8000:8000

   ❌ API timeouts
   > kubectl logs -n ryzanstein-staging deployment/ryzanstein-api -f

   ❌ High error rate (>10%)
   > kubectl top pods -n ryzanstein-staging  # Check resource usage
   > kubectl rollout restart deployment/ryzanstein-api -n ryzanstein-staging
