🔍 KEY PROMETHEUS QUERIES

Test these in Prometheus UI (Graph tab):

1. Verify Prometheus is running:
   up{job="prometheus"}
   Expected: 1

2. Request rate:
   rate(http_requests_total[1m])
   Expected: 0-5 req/sec

3. P99 latency:
   histogram_quantile(0.99, rate(http_request_duration_seconds_bucket[5m]))
   Expected: < 1000ms

4. Error rate:
   rate(http_requests_total{status=~"5.."}[5m]) / rate(http_requests_total[5m])
   Expected: 0 or near 0

5. Per-endpoint breakdown:
   sum(rate(http_requests_total[5m])) by (endpoint)
   Expected: Metrics for each endpoint

📞 TROUBLESHOOTING

Issue: "Connection refused" for a service

Solution:
  • Make sure port-forward window is open
  • Restart port-forward if needed
  • Verify pod is running: kubectl get pods -n ryzanstein-staging

Issue: "No data" in Prometheus queries

Solution:
  • Wait 30 seconds for metrics to appear
  • Check API is running: curl http://localhost:8000/health
  • Verify Prometheus is scraping: http://localhost:9090/targets

Issue: Grafana dashboards empty

Solution:
  • Login with: admin / admin
  • Make sure Prometheus data source is connected
  • Refresh the page
  • Wait 1-2 minutes for data
