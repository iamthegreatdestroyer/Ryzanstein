✨ THREE OPTIONS FOR RUNNING 5 TERMINALS

Option A: VSCode Integrated Terminals (Built-in)
─────────────────────────────────────────────────
  1. In VSCode, press Ctrl+`
  2. Create 5 tabs: Ctrl+Shift+` (repeat 4 times)
  3. Paste one kubectl command in each tab
  4. Press Enter in each
  5. All 5 run side-by-side in tabs

Option B: Windows Terminal (Recommended - Best Visual)
──────────────────────────────────────────────────────
  1. Open Windows Terminal
  2. Create panes: Alt+Shift+D (repeat 4 times for 5 panes)
  3. Paste one kubectl command in each pane
  4. Press Enter in each
  5. All 5 run visible at once in split view

Option C: Separate PowerShell Windows
──────────────────────────────────────
  1. Open 5 PowerShell windows
  2. Paste one kubectl command in each
  3. Press Enter in each
  4. All 5 run in separate windows
