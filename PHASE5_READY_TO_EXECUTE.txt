❓ FAQ

Q: Can I stop the tests early?
A: Yes, press Ctrl+C to stop at any time.

Q: Will tests damage my API?
A: No, they're non-destructive. Safe to run on staging.

Q: Can I monitor while tests run?
A: Yes! Open in parallel:
   - Grafana: http://localhost:3000
   - Prometheus: http://localhost:9090
   - Jaeger: http://localhost:16686

Q: What if a test fails?
A: The script will stop and show an error message.
   Check API logs: kubectl logs -n ryzanstein-staging deployment/ryzanstein-api -f

Q: Can I save the results?
A: Yes, modify the batch file to add: --out json=results.json
