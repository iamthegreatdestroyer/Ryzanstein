Then access:

  • Grafana:     http://localhost:3000 (dashboards, admin/admin123)

Recommended Prometheus Queries:
  • Request rate: rate(http_requests_total[1m])
  • Error rate: rate(http_requests_total{status=~"5.."}[1m])
  • P99 latency: histogram_quantile(0.99, rate(http_request_duration_seconds_bucket[1m]))
  • API CPU: rate(container_cpu_usage_seconds_total{pod=~"ryzanstein-api.*"}[1m])
  • API Memory: container_memory_usage_bytes{pod=~"ryzanstein-api.*"}
