📋 LOAD TEST SPECIFICATIONS

  1. SMOKE TEST (30 seconds)

     ├─ Purpose: Sanity check all endpoints
     ├─ SLO: P95 latency < 500ms
     └─ Expected: All 5 endpoints respond

  2. LOAD TEST (5 minutes)
     ├─ Load: 10 → 25 → 50 VUs (ramping)
     ├─ Purpose: Normal operation validation
     ├─ SLO: P99 < 2000ms, Error < 5%
     └─ Expected: ~300-400 requests, < 5% errors

  3. SPIKE TEST (5 minutes)
     ├─ Load: 10 → 100 → 10 VUs (sudden spike)
     ├─ Purpose: Recovery behavior testing
     ├─ SLO: Error < 10%, Recovery < 2 min
     └─ Expected: Graceful degradation, rapid recovery

  4. STRESS TEST (30 minutes)
     ├─ Load: 100 → 500 → 1000 VUs (aggressive)
     ├─ Purpose: Breaking point identification
     ├─ SLO: Breaking point > 1000 VU
     └─ Expected: Graceful degradation up to 1000 VU

  5. ENDURANCE TEST (60 minutes)
     ├─ Load: 25 VUs (constant)
     ├─ Purpose: Memory leak & stability detection
     ├─ SLO: Latency stable, Error < 2%
     └─ Expected: Consistent performance, no degradation
